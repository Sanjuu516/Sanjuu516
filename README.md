## 🔬 About & Engineering Focus

I am a software engineer focused on building **auditable decentralized systems (Solidity / EVM)**, **high-throughput microservices (FastAPI / Flask / Node.js)**, and **interactive data applications (React 18 / Streamlit / TypeScript)**.

My engineering philosophy centers on **zero-trust verifiable security**, **clean API contracts**, and **responsive user interfaces**:

- ⛓️ **Decentralized Provenance:** Designing state machines in Solidity to trace physical asset movements (blood supplies, organic goods) transparently on-chain.
- ⚡ **High-Performance APIs:** Architecting RESTful and microservice backend systems using FastAPI, Flask, and Express.js paired with MongoDB Atlas and PostgreSQL.
- 🎨 **Modern Interactive Interfaces:** Building real-time single-page web applications with React 18, Streamlit dashboards, Chakra UI, and Chart.js analytics.

## 📐 Engineering Philosophy

> **"Code should be auditable by design, type-safe by default, and delightfully responsive to the user."**

1. 🔒 **Immutable Provenance:** Critical asset states belong on decentralized ledgers where audit trails remain tamper-proof.
2. 🚀 **API Performance:** Clean REST/gRPC endpoints using FastAPI & Express ensure low latency and high concurrency.
3. 🎨 **User-Centric Interfaces:** Complex decentralized backends must be coupled with intuitive React 18 & Streamlit frontends.
